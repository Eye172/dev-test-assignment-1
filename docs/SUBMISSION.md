## Boundaries

This is a clearly labelled synthetic shared demo: public links permit editing profiles, saved strategy and tasks. AI material/history has a single-owner signed-cookie gate, not multi-tenant authentication. Accepted content becomes shared through reviewed application. Commercial deployment requires tenant ownership and agreed data boundaries. No payment processing, investor dashboard or private Black Orbit integration is included.

Document extraction reads text layers and selected XML only; scans, images, charts and speaker notes are not interpreted. Source gaps and vendor limitations stay explicit. AI can return concerns or an invalid proposal; blocking issues prevent application, and ambiguous provider calls are not retried automatically. Continuation uses saved checkpoints when the workspace is reopened rather than an external background queue. Docker is supplied but was not executed on the Windows development host; testing used Chromium emulation rather than physical-device performance certification.
